# 🤖 Telegram Bot

Телеграм-бот для управления внешним сервером.

## 📋 Требования

- [Docker](https://docs.docker.com/get-docker/)
- Токен бота от [@BotFather](https://t.me/BotFather)

## 🚀 Сборка и запуск

### 1. Создайте файл `.env`

В корне проекта создайте файл `.env` и добавьте в него токен:

```env
BOT_TOKEN="ВАШ_ТОКЕН"
```

> [!WARNING]
> Не публикуйте `.env` в репозитории. Добавьте его в `.gitignore`.

### 2. Соберите Docker-образ

```bash
docker build -t backend .
```

### 3. Запустите контейнер

```bash
docker run --rm -it --env-file .env backend
```

| Флаг | Описание |
|------|----------|
| `--rm` | удалить контейнер после остановки |
| `-it` | интерактивный режим с терминалом |
| `--env-file .env` | передать переменные окружения из файла |

## 🛑 Остановка

Нажмите `Ctrl + C` в терминале, где запущен контейнер.
